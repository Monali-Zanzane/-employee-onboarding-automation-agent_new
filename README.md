# -employee-onboarding-automation-agent_new
An AI-powered onboarding assistant designed to streamline and automate the employee onboarding process. The solution provides a single conversational interface for new hires, helping them navigate onboarding tasks, access company information, and track their progress throughout their first 30 days.


Included
Employee profile management
30-day onboarding milestones
Weighted onboarding score
SQLite persistence
Ticket creation and status history
Employee and admin ticket views
Sentiment analysis
Optional Gemini response generation
Offline TF-IDF retrieval
37 separate policy JSON files
